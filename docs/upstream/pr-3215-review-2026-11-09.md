## Findings as posted

Both are about wording only; the code they describe was read at the head and is correct.

### 1. `src/resolution/cpp-includers.ts:165` (doc comment of `cppIncludedSources`)

Says: "Names with no extension are the standard library's (`<vector>`)."

Why it is false: the C/C++ include resolver tries the language's extensions on the spec (`EXTENSION_RESOLUTION`:
`.h`, `.c` for C; `.h`, `.hpp`, `.hxx`, `.cpp`, `.cc`, `.cxx` for C++), then the name as is. So `#include "foo"`
can resolve to the project's `foo.h`, to `foo.c` when there is no `foo.h`, or to an extensionless project header.
`cppIncluders` in the same file already says this (`#include "foo"` can name `foo.h`). The `!name.includes('.')`
skip is kept; only its stated reason is wrong.

Suggested wording (replaces line 165):

```
 * directive. Names with no extension are skipped: most are the standard
 * library's (`<vector>`), though the include resolver tries extensions, so one
 * can name a project file (`#include "foo"` -> `foo.h`, or `foo.c` with no
 * `foo.h`); such a source file is not listed here.
```

### 2. `src/resolution/c-macro-renames.ts:10-13` (file header)

Says: "...so the pass stops at a budget, past which a name is left as written."

Why it overstates: the budget (`HEADER_SCAN_BUDGET`) limits only the shared index built in `memoFor`. A source
file's own renames are outside it: `ownRenames` reads the asking file whenever a name in it is asked about, with
no budget check, and `cMacroRename` adds that file as a candidate. So after the budget is spent, a
`#define sds hisds` in the `.c` file being resolved still renames `sds`. The same holds for an included source
(`impl.c`) the pass skipped, when the name is asked about in that file itself.

Suggested wording (replaces lines 10-13; line 14 follows on unchanged):

```
 * however many files write it. So are the source files something includes
 * (`#include "impl.c"`), which reach their includers as a header does. A
 * vendor's register maps can run to hundreds of megabytes, so the pass stops at
 * a budget: a rename only an unread header or included source writes is not
 * indexed, and the name is left as written there. A source file's own renames
 * are outside the budget. Any other source file reaches
```
